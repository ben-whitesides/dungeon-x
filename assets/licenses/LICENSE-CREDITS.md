## License Compatibility Notes

- **CC-BY-SA 3.0** requires that derivative works using these assets must also
  be shared under CC-BY-SA 3.0 (or a compatible license). This is the most
  restrictive license in this collection.
- **CC-BY 4.0** and **CC-BY 3.0** only require attribution, no share-alike.
- **CC0** assets can be used for anything with no restrictions.
- **OGA-BY 3.0** is OpenGameArt's own attribution license, similar to CC-BY.
- If you mix CC-BY-SA assets with other assets in a single combined work,
  the CC-BY-SA terms may apply to the combined work. Consult the full
  license text if your use case is complex.
